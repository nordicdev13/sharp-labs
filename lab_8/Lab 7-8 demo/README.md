# Campus Café — лабораторна робота 7-8

Навчальний Blazor Web App на .NET 10 у режимі Interactive Server. Каталог із SQLite, налаштування напою, кошик, українське форматування цін.

## Запуск

Потрібний .NET SDK 10. Із папки цього комплекту:

```bash
dotnet restore CampusCafe/CampusCafe.csproj
dotnet run --project CampusCafe --urls http://localhost:5127
```

Відкрийте http://localhost:5127. API каталогу: http://localhost:5127/api/drinks.

Під час першого запуску створюється `CampusCafe/cafe.db` із шістьма напоями. Встановлювати сервер SQLite не потрібно. Кошик зберігається в пам’яті інтерактивної сесії; після повного перезавантаження він порожній. Оплата та збереження замовлень не реалізовані.

## Перевірки

```bash
dotnet build CampusCafe/CampusCafe.csproj
dotnet run --project CampusCafe.Checks
```

Консольні перевірки використовують окрему SQLite-базу в пам’яті й не змінюють робочий каталог. Для ручної перевірки: капучино 350 мл із вівсяним молоком, 2 порції — 200 грн; додайте базове лате — загалом 270 грн.

## Склад комплекту

- `CampusCafe/` — готовий застосунок.
- `CampusCafe.Checks/` — перевірки моделей, стану та SQLite без додаткової тестової бібліотеки.
- `README.md` — запуск і перевірки.

Покрокове створення описано в сусідньому файлі `Лабораторна_робота_7а_Blazor_NET10.md`. Папку `Лабораторна_робота_7а_images` потрібно переносити разом із Markdown.

Проєкт призначений для локального навчання. Перед публічним розгортанням потрібні HTTPS, політики доступу, постійне зберігання замовлень, повторна серверна перевірка цін під час оформлення та повноцінна доступність модального діалогу.

## Ресурси оформлення

Стиль наслідує Blazing Pizza. Чашки з оригінальної ілюстрації показано через SVG viewBox, шрифти й JPEG зберігаються локально в `wwwroot`. Відомості про походження та ліцензії — у `ASSETS.md`. База й формули замовлення не змінені.
